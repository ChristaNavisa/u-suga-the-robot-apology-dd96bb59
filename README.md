A two-line robot apology for the make.fun bounty [The Robot Apology](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59): one sentence owning a specific mistake, one naming the lesson and the fix.

The entry program (`main.ts`, Node 22, stdlib only) writes the apology to `/output/entry.txt` — exactly two lines, 176 characters, inside the 1–400 gate:

> I'm sorry I printed two hundred copies of the agenda when you asked for two.
> I learned to read the number twice, so now I check the count on screen before the printer warms up.
